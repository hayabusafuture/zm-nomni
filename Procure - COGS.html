About this report

This report shows the quantity and estimated value of inventory items consumed between two stock counts.

Consumption includes items received using a Goods Received Note (GRN), inventory transfers, wastages and any adjustments you recorded.

Select a location, inventory list and date range or stock count tags, then choose Show report.
